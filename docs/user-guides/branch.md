# User guide — Branch (Clerk & Branch Leader)

**Roles:** `RecordsClerk` (`clerk@ltjbm.local`), `BranchLeader` (`branch@ltjbm.local`)  
**Home surface:** `/members`

## You can

- Register and update member biodata, household, cell / fellowship, photo
- Review duplicate candidates
- Change status / transfer members (incl. Ghana → international) and read history
- Print individual member sheets and group lists
- Branch Leaders: see membership **scoped to assigned branch(es)** only

## You cannot

- Open **finance**, **reports**, or **admin** — Clerks and Branch Leaders are denied those paths
- Enter pledges, tithes, dues, or batches (HQ Finance only)
- See individual giving unless an authorised finance role is granted (default: no)

## Common tasks

### Register a member
1. Sign in → **Members → Register** (`/members/new`).
2. Enter biodata; attach household; assign cell and/or fellowship; upload photo.
3. Save — member appears on `/members`.

### Duplicates
1. Open **Duplicates** (`/members/duplicates`) or re-register with same phone / name+DOB.
2. Review warning or pending candidate; escalate unclear matches to Admin / Data Centre.

### Status & transfer
1. Open `/members/[id]`.
2. Change status with a reason, or use transfer controls (e.g. East Legon → London).
3. Confirm history shows from→to, when, and reason.

### Print
1. Member detail → **Print** (`/members/[id]/print`) → browser print.
2. **Print group list** (`/members/print`) — filter by branch / cell / fellowship as needed.

### Branch scope (Leaders)
1. Sign in as Branch Leader.
2. Confirm only your branch’s members appear (seed: East Legon for `branch@`).

## Quick checks

- Clerk → `/finance` or `/admin` → forbidden
- After Ghana → international transfer, current branch updates and history retains both sides
